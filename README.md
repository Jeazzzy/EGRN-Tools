# EGRN Tools

**EGRN Tools** — настольное приложение для автоматизации обработки данных ЕГРН  
(XML, ZIP, MIF) с графическим интерфейсом и поддержкой Drag & Drop.

Инструмент предназначен для специалистов, регулярно работающих с выгрузками
Росреестра:

- оценщики недвижимости  
- кадастровые инженеры  
- специалисты БТИ  
- аналитики и технические специалисты  

Приложение не требует знаний программирования и ориентировано на практическое
использование.

---

## Возможности

### 🔹 XML → CSV
- Рекурсивный поиск XML-файлов по маске `proto_*.xml`
- Извлечение URL из тегов `<Stage><URL>`
- Формирование CSV-файла
- Отображение статистики обработки

---

### 🔹 Обработка ZIP (ЕГРН)

Работа с ZIP-архивами, содержащими данные ЕГРН:

- Автоматическое определение вида файла (КПТ или Выписка)
- Поиск XML внутри ZIP
- Извлечение кадастрового номера
- **Переименование ZIP по кадастровому номеру**
- Защита от совпадений имён (`(1)`, `(2)`, ...)
- Распаковка и сортировка файлов:
  - ZIP
  - XML
  - PDF
- Отображение прогресса обработки
- Быстрое Drag & Drop переименовывние XML и ZIP

---

### 🔹 Смена проекции MIF

- Drag & Drop загрузка `.mif` файлов
- Автоматическая замена строки `CoordSys`
- Пакетная обработка файлов

---

## 🖥 Интерфейс

- Графический интерфейс (Tkinter)
- Drag & Drop для ZIP и MIF
- Прогресс-бары
- Разделение функционала по вкладкам

## 📦 Установка и запуск

---

### 🟦 Вариант 1. Готовый EXE (Windows)

Скачайте готовый `.exe` файл из папки **dist** и запустите его.

Python для этого варианта **не требуется**.

---

## 🛠 Вариант 2. Сборка EXE (для разработчиков)

Для сборки исполняемого файла используется PyInstaller:

```bash
pip install pyinstaller
python -m PyInstaller EGRN_Tools.spec
```

Готовый файл появится в каталоге:

```
dist/EGRN_Tools/
```

## ⚠️ Особенности работы

* Кадастровый номер извлекается из XML-тега `cad_number`
* В ZIP используется первый найденный XML-файл
* При совпадении имён ZIP добавляется суффикс (`_1`, `_2`, ...)
